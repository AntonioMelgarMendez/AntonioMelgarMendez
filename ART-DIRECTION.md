# Pixel workspace — art direction

## Intent

A personal GitHub README, not a SaaS landing page. One original illustrated scene, brief profile copy, native Markdown, and a restrained pixel UI. No gradients, rounded technology cards, invented XP/levels, or generic corporate slogans.

- Palette: ink `#101a20`, warm cream `#f2d5a0`, amber `#dea85e`, faded teal `#86b5a6`.
- Typography: original 5×7 pixel glyphs built as SVG paths; normal Markdown for longer text and accessibility.
- UI: hard pixel corners, small original tool symbols, real public GitHub statistics.
- Previous local version is archived under ignored `.preview/v1/`.

## Illustration provenance

- Tool: built-in `image_gen` via the imagegen skill; no CLI/API fallback.
- Final project asset: `assets/pixel-workspace.png`.
- Original generated image copied unchanged into the repository. It represents an imagined workspace, not a photograph of Daniel's actual desk.
- Masthead, section labels, buttons, icons, and statistical panels are separate code-native SVGs; they were not generated by the image model.

## Final generation prompt

```text
Use case: stylized-concept.
Asset type: a panoramic pixel-art illustration for Daniel Méndez's GitHub profile README, not a website mockup.
Create a beautifully composed 3:1 wide pixel-art developer's workbench at night, a complete intimate little environment, reminiscent of a lovingly hand-pixelled 1990s adventure-game background. An empty worn wooden desk with one chunky CRT monitor showing tiny colored code lines, a slim phone on a small stand for mobile development, keyboard, a few handwritten notes, one coffee cup; modest book shelves and a small trailing plant framing the upper scene; a wide window reveals dark tropical mountain silhouettes, scattered town lights, a crescent moon. This is a personal working space, not a futuristic laboratory. Art direction: still, thoughtful, lived-in; strong purposeful silhouette composition and remarkable pixel craftsmanship. Muted petrol teal and dark ink blue shadows, warm amber lamplight, aged cream highlights, sparse terra-cotta. Light is conveyed in flat limited color clusters and disciplined dithering, NEVER gradients or soft glows. Pixel clusters clearly visible, square pixels on a consistent low-resolution grid like a 480x160 source enlarged with nearest neighbor. Every object must be coherent, no noisy AI texture. Straight-on slightly elevated 2D side-view, not an isometric dollhouse. Fill the entire wide frame with the room; clean dark framing edges. No human figures, no animals, no random decorative objects. No legible lettering, no logos, no UI panels, no title, no watermarks, no rounded cards, no generic cyberpunk purple/pink lighting. Desired aspect ratio 3:1. Illustration only; identity text will be separate accessible markup.
```
